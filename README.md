# ApplyTrack Dashboard

ApplyTrack Dashboard is a small React project for organizing job applications during a job search.

I built it to practice React state, forms, routing, filtering, sorting, and saving data in the browser with localStorage. The app is intentionally simple, but it covers the main CRUD features a small dashboard needs.

## Features

- Add, edit, view, and delete job applications
- Dashboard with basic application statistics
- Search by company, position, location, or notes
- Filter by application status
- Filter applications that need follow-up
- Sort by newest, oldest, company name, or follow-up date
- Track priority and follow-up date for each application
- Data saved in localStorage
- Responsive layout for desktop and mobile

## Tech Stack

- React
- Vite
- React Router
- CSS
- localStorage
